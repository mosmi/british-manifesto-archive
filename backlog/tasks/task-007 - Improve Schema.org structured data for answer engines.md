## Context
The site already injects per-route SEO metadata and some JSON-LD from `functions/_middleware.js`, using `data/seo.json` generated by `scripts/build-seo-data.py`.

Current live pages expose basic JSON-LD for:
- Manifesto pages: `DigitalDocument`
- General election pages: `Event`
- Party pages: `Organization`

To make the archive easier for search engines and answer engines to understand, extend the existing edge-rendered JSON-LD into a fuller connected Schema.org graph. Prefer server/edge-rendered JSON-LD over client-only injection because the SPA content is JavaScript-rendered.

## Acceptance criteria
- [x] Homepage and `/about` include a site-level JSON-LD graph describing the archive as `WebSite`, `Organization` or `ArchiveOrganization`, and `Dataset` or `DataCatalog`.
- [x] Manifesto pages keep `DigitalDocument` but add stable `@id`, richer document metadata, PDF/HTML/Markdown encodings where available, cover image, free-access flag, election reference, topic keywords from manifesto frontmatter where available, and copyright/provider clarity.
- [x] Election, party, manifesto, devolved, and collection routes include `BreadcrumbList`.
- [x] Collection pages such as `/elections`, `/parties`, `/election/:id`, `/party/:id`, and devolved election pages include `ItemList` where the page visibly lists archive items.
- [x] Party JSON-LD supports `sameAs` values when reliable source URLs are available.
- [x] Add or generate a public JSON-LD catalogue feed, e.g. `/data/catalog.jsonld`, and link it from the homepage with `<link rel="alternate" type="application/ld+json" href="/data/catalog.jsonld">`.
- [x] Do not add `FAQPage` unless a visible FAQ exists.
- [x] Do not add `SearchAction` unless the site has a real crawlable query URL.
- [x] Document that live Cloudflare-managed crawler/content-signal settings may differ from committed `robots.txt`; do not overwrite those settings blindly. (See `knowledge/architecture/structured-data.md`.)

## Implementation notes
- Primary code targets are `scripts/build-seo-data.py` and `functions/_middleware.js`.
- Extend `data/seo.json` only from existing sources of truth: `js/data.js`, `data/manifestos-index.json`, manifesto frontmatter, and existing asset paths.
- Keep JSON-LD injected by Cloudflare middleware so direct deep links expose schema before the SPA boots.
- Bump cache query strings in `index.html` if any `js/*.js` or CSS assets change.
- If durable facts are discovered during implementation, add them to `knowledge/` and append a short entry to `knowledge/log.md`.
