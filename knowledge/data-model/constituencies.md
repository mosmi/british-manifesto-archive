# Constituencies (`data/constituencies/`)

One file per election year plus an `index.json`. Files are named by election id:
`1945.json` … `2024.json`, with the 1974 pair as **`feb1974.json`** and
**`oct1974.json`**.

These drive the constituency-level maps and tables. Constituency boundaries change
between elections (9 boundary sets cover 1945–2024) — the hex cartograms that
visualise these live in `data/hex/` and are generated by the hexmaps pipeline; see
[pipelines/hexmaps](../pipelines/hexmaps.md) for the authoritative boundary-set table
and name-matching rules.

When adding or correcting a constituency result, check whether the same correction
needs to flow into the hex layer (`data/hex/`) and re-generate the relevant hexjson.
