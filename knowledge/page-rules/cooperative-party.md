# Co-operative Party representation

## The rule (do not violate)
Treat Labour/Co-operative representatives as elected Co-operative Party legislators
**only on `/party/cooperative`**. **Leave all Labour results on every other page
exactly as they are.** Co-op candidates normally stand jointly as Labour & Co-operative
(or under a Labour description in some devolved/list elections); splitting Labour and
Co-op anywhere else would misrepresent the results and confuse users.

## Canonical counts
**Currently sitting:** Commons 41 · Holyrood 11 · Senedd 3.
Note the distinction the page must preserve: *elected at election* vs *currently
sitting* — e.g. Westminster 2024 = **43 elected**, Commons current = **41 sitting**.
